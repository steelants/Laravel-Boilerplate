# Components

SteelAnts Laravel-Boilerplate provides Blade components under the `boilerplate::` prefix.

| Component | Tag | Description |
|---|---|---|
| [Tab Group](components/tab.md) | `<x-boilerplate::tab.group>` | Bootstrap tabs with Alpine.js state and cookie persistence |
| [Breadcrumb](components/breadcrumb.md) | `<x-boilerplate::breadcrumb>` | Bootstrap breadcrumb from an associative array |
| [Gantt](components/gantt.md) | `<x-boilerplate::gantt>` | Horizontal Gantt chart with day/week/month scale |
| [Pie Graph](components/pie-graph.md) | `<x-boilerplate::pie-graph>` | Chart.js pie chart |
| [Selectbox](components/selectbox.md) | `<x-boilerplate::selectbox>` | Alpine.js select with tags mode and multi-select |
| [Selectbox Ajax](components/selectbox.md#selectbox-ajax) | `<x-boilerplate::selectbox-ajax>` | Selectbox with server side Livewire search |
| [Searchbox](components/searchbox.md) | `<x-boilerplate::searchbox>` | Client side filtered dropdown search |
| [Alert](components/alert.md) | `alert()->success()->now()` | Snackbar notifications for Livewire and HTTP contexts |

Each component has its own detailed documentation page.


## Livewire Components
