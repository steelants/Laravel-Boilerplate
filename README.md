## Features

SteelAnts Laravel-Boilerplate provides:

- Responsive app template (Bootstrap, Livewire, light/dark theme)
- User management
- Job management
- Cache management
- Backup manager
- Log viewer
- Audit log
- API routes page
- Menu builder
- Alert system
- CRUD generator
- UI components (tabs, breadcrumb, gantt, pie graph, selectbox, searchbox)
- Quill editor
